# 第三阶段：条件有效性、校准预算与抗漂移边界

## 信息过滤族与审查结论

对每个客户端固定受监控标量方向或使用在过去可测的方向，观测 X_(i,t)∈[-1,1]。F_(t-1) 包含此前所有模型、参与集合、客户端更新、隔离记录、独立外部正常参考、校准结果和算法随机性；本轮外生协变量 C_t 与参与选择在更新前揭示，扩展信息集为 G_t=F_(t-1)∨sigma(C_t,S_t)。F_t 加入本轮结果。

本轮预测均值 muhat_t、误差界 b_t、方向、备择下注 a 以及混合权重必须 G_t 可测。只是在程序中先计算它们不够：使用的文件/参考也必须在此时真实可得。`ExternalReference` 要求 observed_round < available_round <= current_round；隔离目标更新不能直接作为参考。provenance 字符串不认证其来源。

生产代码固定下注集合 a∈{±.125,±.25,±.5,±1,±2}，混合权重固定为 .1。压力测试先生成快照和界，后生成目标观测；独立参考在该轮结束产生，下一轮才加入。主训练代码冻结所有预测后才训练客户端，并在聚合前执行观测回调。没有根据测试攻击标签选下注、界或阈值。真实训练的外部文件是否独立可信仍需用户/数据流程认证。

## 条件零假设与备择

记 m_t=E[X_t|G_t]。

- H0：对整个监控期间每个参与轮，|m_t-muhat_t|<=b_t，且支持集为 [-1,1]，参与与参数均可预测。
- H1：某些轮次的条件均值超出包络。要检出还需累计方向信号足够强，以抵消二次罚项、误差补偿和攻击前财富衰减。
- “良性客户端”不是 H0 的同义词。良性但未建模的漂移可以违反 H0；不改变方向均值的攻击可以仍处在 H0 中。不能对后者宣称普遍检出。

## 条件次高斯与 Hoeffding 参数

真正所需的是中心化变量 X_t-m_t 的条件矩母函数控制，不是对未经中心化或随意标准化残差假设高斯。

若条件支持集 [A_t,B_t] 可预测，长度 R_t=B_t-A_t，则条件 Hoeffding 引理给出

\[
E[\exp\{a(X_t-m_t)\}\mid G_t]\le \exp(a^2R_t^2/8)
=\exp(a^2\sigma_t^2/2),\quad \sigma_t^2=R_t^2/4.
\]

当前通用实现用 [-1,1]，故 R=2、sigma²=1，补偿项是 a²/2。压力测试虽有更小的真实均匀噪声，也没有事后改用经验方差提高功效。若观测区间换为 [-c,c]，应使用 sigma²=c²；若是 [0,1]，应使用 sigma²=1/4。不能把 sigma² 与区间宽度、经验方差混为一谈。

## 指数过程与有限混合的完整证明

对固定 a 定义增量

\[
Q_t^a=\exp\{a(X_t-\widehat\mu_t)-|a|b_t-a^2\sigma_t^2/2\}.
\]

由条件 Hoeffding 和 H0，

\[
E[Q_t^a|G_t]\le \exp\{a(m_t-\widehat\mu_t)-|a|b_t\}\le1.
\]

令 L_0^a=1，L_t^a=L_(t-1)^a Q_t^a。L 非负，过去财富可测，因此

\[
E[L_t^a|G_t]\le L_{t-1}^a;
\quad E[L_t^a|F_{t-1}]\le L_{t-1}^a
\]

（第二步用塔式法则）。未参与轮取 Q=1。有限组固定非负权重 w_a、sum w_a=1 给出 E_t=sum w_a L_t^a，仍为初值 1 的非负超鞅。实现保留每个 a 的累计 log L，再用 log-mean-exp；没有每轮重新混合，没有在漂移或报警后清零。

如果改为预测性动态下注 a_t，则每个乘积可使用可预测 a_t 和对应罚项；但不能观察 X_t 后选择符号。也不能随意重新选择已积累 L 的混合权重来追逐表现；那需要自融资组合等单独证明。

Ville 不等式：P_H0(exists t:E_t>=1/alpha_e)<=alpha_e。它控制任意时刻的至少一次报警，而非每轮 p 值。客户端可用 alpha_(e,i) 预先分摊并取并集界；客户端之间不必独立，但条件假设必须相对于完整信息集成立。

## 三种误差界与它们的前提

### 固定历史：双锚点条件预测

假设一个固定客户端的正常条件均值在 c∈[-1,1] 上确为仿射函数 m(c)=theta_0+theta_1 c，且随时间不变。外部独立正常样本在 c=-1,+1 各 n 个，值有界 [-1,1]。不从待检测目标更新采样。两锚点样本均值为 mhat_-、mhat_+。

独立有界均值的双侧 Hoeffding 界为

\[
P(|\bar Y-EY|>\epsilon)\le2e^{-n\epsilon^2/2}.
\]

对两锚点使用并集界，选

\[
\epsilon_A=\sqrt{2\log(4/\delta_A)/n},\quad
\widehat m(c)={(1-c)\widehat m_-+(1+c)\widehat m_+\over2}.
\]

以至少 1-delta_A 的概率，所有 c 同时有 |m(c)-mhat(c)|<=epsilon_A，因为权重非负且和为 1。因此 b_fixed=epsilon_A 是一个**在明确仿射、稳定与独立参考前提下**的高概率同时包络，不是自动适用于真实 FL 的严格界。

对真实高维方向不能用同一批数据选择方向后直接套一维独立均值界；需要预先固定方向、样本拆分或对全部方向的统一界。本次压力测试固定标量方向，不存在这一步的数据重用。

### 滚动历史：独立参考残差校准

保留最近 n 个已独立验证的正常参考，不吸收目标更新。固定锚点模型 mhat_A(c) 后，过去参考残差为 R_j=Y_j-mhat_A(c_j)。预测

\[
\widehat m_R(c_t)=\widehat m_A(c_t)+n^{-1}\sum_{j\in W_t}R_j.
\]

已知参考的条件支持宽度仍≤2；减去其确定的预测值不改变宽度。对预先确定的有限 T 个窗口并集校准，取

\[
\epsilon_R=\sqrt{2\log(2T/\delta_R)/n}.
\]

在锚点事件上，仿射残差均值 r(c)=m(c)-mhat_A(c) 的斜率误差绝对值≤epsilon_A。由三角不等式

\[
|m(c_t)-\widehat m_R(c_t)|
\le\epsilon_R+\epsilon_A\,n^{-1}\sum_{j\in W_t}|c_t-c_j|.
\]

这就是滚动包络。重叠窗口可相关，并集界仍成立；不需要窗口彼此独立。但这里要求参考样本在给定外生上下文路径时独立，样本准入不由目标报警或样本值自适应筛选，且参考对应相同的稳定仿射正常规律。若协变量根据已观察参考自适应选择或真实正常函数随时间变化，不能直接使用这一证明，需要鞅回归或额外漂移补偿。

实现将预测投影到 [-1,1]、误差界最多截到 2，这不会增加到真实有界均值的距离。使用滚动窗口不等于自动适应任意动态漂移。该证书的 delta_R 只覆盖固定 T=240 轮；之后不能继续宣称同一证书无限有效，需可求和预算或时间一致校准界。

### 保守预测不确定性界

对任意 muhat∈[-1,1]，令 b=1+|muhat|。所有可能的条件均值 m∈[-1,1] 都满足 |m-muhat|<=b，故不依赖历史分布或仿射假设。

这是无校准失败概率的确定性界，但 a(X-muhat)-|a|b<=0，每个下注财富均不增，几乎没有检测用途。它作为保守负对照，揭示“无需分布假设就有误报控制”与“有足够功效”之间的代价，不能把它的零报警宣传为成功。

## 校准失败预算与总误报预算

压力测试每个 alpha∈{.01,.05,.10} 预先分配 delta=.1alpha，alpha_e=.9alpha。固定策略全部 delta 给两锚点；滚动策略把 delta 再均分给锚点与滚动窗口。保守策略本不需要 delta，为保持阈值可比仍用同一 alpha_e（不影响无功效结论）。

高概率校准事件不是“在所有已实现历史上都成立的条件假设”。正确表述是：以概率≤delta 发生包络失败；对分析中在首次包络失效前停止的财富应用超鞅/Ville，再并集失败事件，得

\[
P(\text{至少一次误报})\le\alpha_e+\delta=\alpha.
\]

停止时刻由真实条件均值定义，仅用于证明，无需算法能观察它；包络失效在下注前对包含真参数的分析信息可判定。外部参考与目标不能通过不受控选择互相泄漏，否则必须重建证明。总系统目标还需跨客户端、重复实验或重启分配预算。三个 alpha 的配对模拟是三个独立评估目标，不意味着三个测试并行运行时仍只有最小 alpha 的家族错误率。

## 抗漂移与无法消除的限制

已观察上下文解释的动态/渐进漂移在稳定 m(c) 内，条件预测可保留上述保证；普通固定均值可能有明显预测偏差。额外的未观察漂移使 m(c,t) 改变，仿射稳定性证明失效，即便经验误报率恰好小也不能继续宣称有效。

正常变化与恶意变化若在可观察信息上产生相同分布，就不能同时无条件区分。没有可信参考、漂移结构或独立标签，任意漂移鲁棒且任意弱攻击高检出的主张不成立。

本阶段的低维标量实验只验证一个可证明的特例。主 CIFAR 脚本的方向随模型/历史确定，且真实数据不满足已验证的仿射参考模型；`--mean-error-bound` 仍是外部声明的假设，不能由本模拟认证。
